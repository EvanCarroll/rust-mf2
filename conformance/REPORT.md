## Notes

* `unpaired-surrogates` — n/a: test/README.md asks implementations whose strings can hold unpaired surrogate code points to add syntax-error tests for them (e.g. src "{\ud800}"). Neither the JSON suite nor a Rust &str can represent an unpaired surrogate, so such input cannot reach any layer: N/A by construction.
* `stripped-formats-identically` — pass: Production catalogs are stripped of COLD and IDS (plans/02-catalog-format.md §2.3), which must not change formatting. L3 checks that the stripped catalog decodes to the formatting-relevant model of the unstripped one (conformance/src/l3.rs); since Phase 3, L4 formats every L4-applicable test from both catalogs and requires identical string output, parts and errors (conformance/src/l4.rs), so a difference fails that test's L4 cell.
